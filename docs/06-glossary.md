# 06 · מילון מונחים

המונחים שמופיעים בתיעוד של מערכת ה-ERP-AI של קילוהרץ, בהסבר קצר ובהקשר של הפרויקט.

| מונח | הסבר |
|---|---|
| ERP (Enterprise Resource Planning - תכנון משאבי הארגון) | מערכת שמרכזת במקום אחד את נתוני התפעול של העסק: מסמכי מס, לידים, מוצרים ומשימות. כאן היא בנויה מ-Airtable, n8n ואפליקציית ניהול. |
| n8n | פלטפורמת אוטומציה שבה בונים תהליכים מקוביות (צמתים) על קנבס, בלי לכתוב קוד. מריצה את כל התהליכים והסוכנים בפרויקט. |
| Workflow (תהליך עבודה) | רצף צמתים ב-n8n שמבצע משימה אחת מוגדרת, למשל WF01 שמאמת חשבונית חדשה. |
| Node (צומת) | שלב בודד בתהליך: קריאה מ-Airtable, תנאי, שליחת מייל וכדומה. הפלט של צומת הוא הקלט של הצומת הבא. |
| Trigger (מפעיל) | הצומת הראשון בתהליך, שקובע מתי התהליך מתחיל לרוץ: הודעה, בקשת רשת, תזמון או הפעלה ידנית. |
| Webhook (נקודת קליטה) | כתובת אינטרנט שמחכה לבקשות. כשמערכת אחרת שולחת אליה נתונים, התהליך מתחיל. WF03 ו-WF13 מופעלים כך. |
| Poll (סריקה חוזרת) | בדיקה קבועה של מקור נתונים כדי לגלות מה חדש. WF01 סורק את Invoices כל דקה, ו-WF04b סורק את Gmail כל 30 דקות. |
| Schedule (תזמון) | הפעלת תהליך במרווח זמן קבוע, בלי קשר לאירוע. WF04a רץ כל 3 שעות ו-WF08 כל דקה. |
| AI Agent (סוכן בינה מלאכותית) | מודל שפה שמקבל מטרה, כלים והנחיות, ומחליט בעצמו באיזה כלי להשתמש כדי לענות. במערכת יש שלושה: מנהל, שירות לקוחות ומכירות. |
| Tool (כלי) | פעולה שהסוכן רשאי להפעיל, למשל חיפוש משימות או חיפוש במדיניות. הסוכן יכול לדעת ולעשות רק את מה שהכלים שלו מאפשרים. |
| System Prompt (הנחיית מערכת) | ההוראות הקבועות שהסוכן מקבל לפני כל שיחה: מי הוא, מה מותר לו, ממה הוא עונה ומתי מפנה לנציג. |
| RAG (Retrieval-Augmented Generation - שליפה מועשרת) | שיטה שבה לפני התשובה שולפים קטעים רלוונטיים ממסמכי העסק ומעבירים אותם למודל, כדי שיענה מהם ולא מהזיכרון הכללי שלו. |
| Embeddings (ייצוג וקטורי) | המרת טקסט לרשימת מספרים שמייצגת את המשמעות שלו, כך שטקסטים בעלי משמעות דומה מקבלים מספרים קרובים. |
| Vector Store (מאגר וקטורי) | מאגר שמחזיק את ה-Embeddings ומאפשר לחפש לפי משמעות ולא לפי מילים מדויקות. WF06 ו-WF07 ממלאים אותו. |
| Chunk (מקטע) | חלק קצר ממסמך ארוך. המדיניות מפוצלת למקטעים לפני ההמרה, כדי שהשליפה תחזיר רק את החלק הרלוונטי. |
| Memory (זיכרון שיחה) | ההודעות האחרונות בשיחה, שנשמרות לפי מזהה השיחה, כדי שהסוכן יבין שאלת המשך. |
| Airtable | בסיס נתונים בענן עם ממשק של גיליון. כאן הוא מקור האמת היחיד לחשבוניות, ללידים, למוצרים ולמשימות. |
| PAT (Personal Access Token - אסימון גישה אישי) | מפתח גישה ל-Airtable שנוצר עם הרשאות מוגדרות ולבסיס מסוים בלבד. n8n משתמש בו כדי לקרוא ולכתוב רשומות. |
| OAuth (פרוטוקול הרשאה מואצלת) | דרך לתת ל-n8n גישה ל-Gmail ול-Drive דרך מסך אישור של Google, בלי למסור לו את הסיסמה. |
| Credential (פרטי גישה) | פריט מוצפן ב-n8n שמחזיק מפתח או הרשאה לשירות חיצוני. התהליכים מפנים אליו, והסוד עצמו לא מופיע בקובצי התהליכים. |
| Secret (סוד) | ערך רגיש, כמו מפתח API או כתובת פרטית, שנשמר רק בצד השרת: ב-Credentials של n8n או במסך הסודות של האפליקציה. לעולם לא בקוד ולא בריפו. |
| Lovable / Base44 | פלטפורמות שבונות אפליקציית ווב מתיאור בשפה חופשית. בפרויקט בוחרים אחת מהן לבניית ממשק הניהול. |
| מע"מ (VAT - Value Added Tax - מס ערך מוסף) | מס שמתווסף למחיר העסקה: 18% ממסמכים מ-01/01/2025, ו-17% למסמכים שתאריכם לפני כן. WF01 מחשב אותו לפי תאריך המסמך. |
| חשבונית מס | מסמך מס רשמי שמפרט את העסקה, את המע"מ ואת הסה"כ, ומאפשר לעוסק מורשה לקזז מע"מ. |
| קבלה | מסמך שמאשר שהתשלום התקבל בפועל. אינה מסמך שמאפשר קיזוז מע"מ. |
| Lead (ליד - לקוח פוטנציאלי) | אדם או עסק שהשאירו פרטים ועוד לא קנו. בטבלת Leads הוא עובר בין הסטטוסים New, Contacted, Replied ו-Unsubscribed. |
