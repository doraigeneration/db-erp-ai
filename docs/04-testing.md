# 04 · בדיקות ואימות

המסמך מפריד בין שני דברים: מה **נבדק בפועל** במהלך הפיתוח, ומה נבדק **בהקמה החיה** מול השירותים האמיתיים.

## א. מה נבדק בפועל בפיתוח
הבדיקות רצו על **n8n 2.19.5 מקומי ב-Docker**, עם Credentials מדומים (Dummy) שלא מתחברים לשירות אמיתי. את הלוגיקה בדקנו בתהליכי בדיקה זמניים: נתוני דמה **במבנה שבו Airtable באמת מחזיר רשומה** (`{id, createdTime, fields:{…}}`) הוזנו לעותקים של הצמתים האמיתיים (Edit Fields, IF ו-Switch), והתהליכים הורצו עם `n8n execute`.

| בדיקה | תוצאה |
|---|---|
| כל 10 הקבצים הם JSON תקין ונטענים ל-n8n (`import:workflow`) | 10/10 |
| אין צמתי Code | 0 צמתי Code |
| שמות הפרמטרים תואמים להגדרות הצמתים בגרסה המותקנת | עבר |
| **WF01: מע"מ** | 31/12/2024 → שיעור 0.17, מע"מ 170, סה"כ 1170, `Pending`. 01/01/2025 → שיעור 0.18, מע"מ 222.21 (על 1234.50), סה"כ 1456.71, `Pending`. רשומה חסרה → `Invalid` עם סיבה בעברית |
| **WF03: ניקוי וכפילויות** | אימייל באותיות שונות זוהה ככפול. אימייל חסר, לא תקין או עם מירכאות נדחה עם 400 |
| **WF04b: סיווג תשובה** | ליד ב-`Contacted` → `Replied` ומשימה "לחזור לליד: …". "הסר" → `Unsubscribed` בלי משימה. "הסרת רעשים" לא נחשבת בקשת הסרה. שולח שאינו ליד מקבל התעלמות |
| **WF08: מספור ומסמך** | המספר האחרון 1004 → 1005. אין מסמך קודם → 1001. ה-HTML מכיל `₪ 1,234.50`, `₪ 222.21` ו-`₪ 1,456.71`, ולא נשארו בו ביטויים שלא חושבו |
| **WF09: תמונת מצב** | הסכומים נכונים, כולל מצב של טבלה ריקה |
| **WF13: ניתוב ואבטחה** | 7 מקרי בקשה נותבו לענף הנכון. בלי מפתח → 403. פעולה לא מוכרת, טבלה לא מורשית או צ'אט ריק → 400 עם `{ok:false,error}` |
| **WF05 ו-WF06** | הטעינה והפיצול עובדים. העצירה היא רק בשגיאת 401 הצפויה מהמפתח המדומה |
| **אפליקציית הייחוס** (Playwright, ב-1440px וב-390px) | אין שגיאות בקונסול ואין גלילה אופקית. סינון, חיפוש, חישוב מע"מ ויצירת רשומה עובדים במצב הדגמה |
| **ביקורת-נגד** | סקירה מלאה של הריפו מול מסמך המשימה. נמצאה טעות במבנה השדות של Airtable ב-WF04a, WF04b ו-WF08. היא תוקנה ונבדקה מחדש (השורות למעלה) |

**מה לא נבדק בשלב הפיתוח:** קריאות אמיתיות ל-OpenAI, Telegram, Gmail, Drive ו-Airtable. הן דורשות מפתחות אמיתיים, ונבדקות בהקמה החיה לפי סעיף ב.
